# Extract decisions and action items from meeting notes

1. Separate decisions made, proposals and unresolved questions. Treat an offer to help as an assignment only if the notes confirm ownership.
2. Record each action with its owner, due date and evidence in the notes. Mark missing fields as unassigned or undated.
3. Return a forwardable recap and an action table. Raise conflicting assignments as one question for the meeting owner.
