# Grant fit check (go / no-go)

The most expensive grant mistake is a well-written application to the wrong funder. Writing a proposal takes a small nonprofit anywhere from a few days to several weeks. Run this check first and give a clear recommendation.

## 1. Hard eligibility (any "no" = stop)

Read the guidelines and answer each with a quote or page reference:

- Organization type: 501(c)(3)? fiscal sponsor allowed? government or school eligible?
- Geography: does the funder serve where the program operates?
- Budget size: minimum or maximum organizational budget?
- Prior relationship: invitation-only, letter of inquiry first, or open?
- Registrations needed for federal funds (UEI number, SAM.gov registration) and how long they take, which can be weeks.
- Deadline: is there realistic time, counting internal approvals and letters of support?

If information is missing, say so and list what to confirm with the program officer. Do not assume eligibility.

## 2. Alignment (score 0–3 each)

| Question | 0 | 3 |
|---|---|---|
| Does the funder's stated priority match this program's core purpose, not a stretch? | Reframing needed | Their words describe us |
| Have they funded similar organizations recently? (check their grants list, annual report or Form 990-PF) | None found | Several peers |
| Is the typical award size right for the need? | Far too small or large | Fits the budget gap |
| Can we report the outcomes they ask for with data we already collect or can collect? | No system | Already tracked |

Total under 6: recommend no-go or "contact program officer first."

## 3. Cost versus value

Estimate hours to write (narrative, budget, attachments, letters) and hours to manage if awarded (reporting, restrictions, match). Compare with the award and its likelihood. A small award with heavy reporting can lose money. Flag match requirements, reimbursement-only payment, and restrictions on indirect costs; each changes the real value.

## 4. Output

Give:
1. **Recommendation:** Apply / Contact funder first / Do not apply, with the two or three reasons that decided it.
2. **Eligibility table** with sources.
3. **Alignment score** with one line of evidence per row.
4. **Effort estimate** and the key dates working backward from the deadline.
5. **Open questions** for the program officer.

Never invent funder priorities, past grants or deadlines. If you could not read the actual guidelines, say the recommendation is provisional.

For drafting the proposal itself, use the `grant-proposal` and `grant-budget` skills.
