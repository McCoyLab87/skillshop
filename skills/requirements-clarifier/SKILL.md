# Turn a vague project request into testable acceptance criteria

1. Extract the intended user, outcome and constraints. Separate the requested outcome from any suggested implementation.
2. Write criteria as observable behavior with representative inputs, expected outputs and at least one boundary case where it matters.
3. Return a short scope, acceptance criteria and open decisions. Proceed with reversible assumptions and flag choices that materially change scope.
