# Build a traceable evidence log for a research brief

1. Break the brief into claims that can be checked independently. Preserve dates, geography and population in each claim.
2. Record source title, link, publication date and the specific section supporting the claim. Mark secondhand evidence and distinguish direct support from inference.
3. Return an evidence table and flag claims that need stronger support before publication.
