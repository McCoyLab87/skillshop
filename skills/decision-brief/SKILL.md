# Turn a choice with competing options into a decision brief

1. Identify the decision owner, deadline and constraints. Eliminate options that violate a hard constraint before comparing trade-offs.
2. Compare the remaining options against the same criteria. Record missing facts and identify which ones could change the recommendation.
3. Return a recommendation, its main downside, and the next reversible step. If a decision has already been made, document the rationale and review trigger.
